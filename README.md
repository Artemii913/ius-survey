# Анкета IUS с отправкой в Google Таблицу

Статическая страница для GitHub Pages, без сборки и внешних библиотек. В начале отдельные поля «Имя», «Возраст», «Пол». Участник видит результат сразу после заполнения, а обработчик Google Apps Script записывает анкету в закрытую Google Таблицу.

## Текущий статус

Форма, подсчёт, запись, подтверждение получения, защита от дублирования и тесты реализованы. GitHub Pages включён: https://artemii913.github.io/ius-survey/ . Обработчик Google Apps Script опубликован и прописан в настройках. Тексты 27 утверждений ещё не предоставлены владельцем: `questions` в `docs/config.js` пуст. Пока нет 27 формулировок, страница показывает сообщение о подготовке и не собирает данные. Текущие варианты ответа и пояснения являются временными и не заявлены как дословная версия исходной анкеты.

## Расчёт

Все 27 ответов обязательны, каждый оценивается от 1 до 5. Веса одинаковы, обратных пунктов и подшкал нет. Сумма от 27 до 135. Диапазоны: 27–62, 63–98, 99–135. Пол, имя и возраст не меняют результат. Диапазоны воспроизводят реализацию https://gabaidulin.ru/ius, проверенную 04.11.2026, и не являются диагностическими порогами. На сервере балл вычисляется заново из ответов, клиентская сумма не принимается на веру.

## Настройка

1. Откройте https://script.google.com/home и создайте проект. Поместите `apps-script/Code.gs` в редактор. В настройках проекта включите отображение `appsscript.json` и замените его содержимым одноимённого файла, чтобы явно ограничить запрашиваемые разрешения работой с Google Таблицами.
2. Выполните `setup()` один раз. Google запросит разрешение на работу с таблицами. В журнале появится ссылка на созданную закрытую таблицу. Её ID хранится только в свойствах скрипта. Повторный запуск `setup()` использует ту же таблицу и не удаляет ответы.
3. «Начать развёртывание» → «Новое развёртывание» → «Веб-приложение». Выполнять от вашего имени; доступ — «Все», включая пользователей без Google-аккаунта. Публикуется только приёмник анкет: функция `doGet()` не возвращает сохранённые ответы. Таблица остаётся закрытой. Скопируйте опубликованный URL, заканчивающийся на `/exec`.
4. В `docs/config.js` укажите URL в `endpoint`, 27 предоставленных вами формулировок в `questions`, пять подписей в `options`, пояснения трёх диапазонов в `bands[].text`, организатора и контакт. Для подготовки файла есть `docs/setup.html`: вставка текстов и скачивание настройки происходят локально, без отправки на сервер.
5. Загрузите репозиторий на GitHub. Settings → Pages → Deploy from a branch → main → `/docs` → Save. Не публикуйте таблицу, реальные ответы, токены или файлы авторизации.
6. Пройдите опубликованную форму вымышленными данными. Проверьте появление строки в таблице и сообщения о сохранении на странице. Такая проверка обязательна: локальные тесты не проверяют доступность реального развёртывания, Google OAuth, ограничения аккаунта или CORS.

## Что хранится

Для технической проверки соединения есть `docs/verify-delivery.html`: по нажатию кнопки она отправляет вымышленную анкету дважды с одним ID, не используя персональные данные. В таблице должна появиться одна строка «ТЕСТ ПОДКЛЮЧЕНИЯ» с суммой 81. Эта страница проверяет сервер и CORS с фактического адреса GitHub Pages, отдельно от текстов анкеты. Сквозная проверка выполнена 04.11.2026: оба подтверждения получены в браузере, в Google Таблице проверено наличие одной строки с тем же ID.

Одна отправка = одна строка, 39 столбцов: серверная дата, UUID отправки, версия, имя, возраст, пол, числовые ответы 1–27, сумма, уровень, полный текст результата с ответами, дата на устройстве, согласие, хеш отправки. Столбцы 34–35 сервер вычисляет сам; столбец «Полный результат» сохраняет снимок текста, показанного участнику. Дата на устройстве — справочная, основная дата создаётся сервером.

Повторная отправка использует тот же UUID. Запись сериализуется через `LockService`; проверка существующего ID и хеша не даёт повторной попытке создать дубль. Изменённая анкета с тем же ID отклоняется. Текстовые поля защищены от интерпретации как формулы. Ответы не сохраняются в localStorage, URL, cookies или сторонней аналитике. При закрытии вкладки незавершённая отправка теряется; участник может скачать текст заранее.

## Отправка и ограничения

Используется POST с FormData и читаемый JSON-ответ, без `no-cors` и ложного подтверждения успешной записи. Google Content Service перенаправляет ответ; запрос допускает перенаправления. Время ожидания — 30 секунд. При сетевом сбое запись могла уже состояться: повтор безопасен благодаря UUID. Ответ появляется независимо от успешности сохранения, статус записи показан отдельно. При изменении конфигурации нужно обновить версию параметра `config.js?v=…` в HTML: браузер и CDN могут некоторое время сохранять предыдущую настройку.

Опубликованный адрес приёмника виден в клиентском коде. Это ожидаемо для анонимной формы, URL не является секретом. Проверка формата и скрытое поле от простых ботов не заменяют защиту от целевого спама. При открытом массовом распространении стоит добавить проверяемую сервером CAPTCHA и при необходимости отдельный прокси с ограничением частоты запросов. Квоты Apps Script ограничивают нагрузку. Автоматическое удаление строк по сроку хранения пока не настроено.

Официальное описание развёртывания: https://developers.google.com/apps-script/guides/web . Разрешения веб-приложения: https://developers.google.com/apps-script/manifest/web-app-api-executable .

## Проверка кода

Требуется Node.js 20+:

```sh
node --test tests/scoring.test.cjs
node --check docs/app.js
```

Тесты проверяют все 109 возможных сумм, границы диапазонов, независимость от демографии, некорректные ответы и поля, повторную отправку, подмену UUID, ошибку записи и защиту текстовых полей от формул. Серверные тесты используют изолированную модель сервисов Apps Script и не создают реальные данные.

Локальный просмотр: `python -m http.server 8765 --directory docs`, затем http://localhost:8765/ . Страница настройки: http://localhost:8765/setup.html .
